NAS 上的 Docker 容器怎么走代理：设置思路

一、两种场景

一是 Docker 守护进程拉取镜像，二是容器内部的程序访问外网。它们的代理设置位置不同，需要分别处理。

二、守护进程的代理

在 Docker 服务的配置里设置代理环境变量，然后重载并重启服务。NAS 的图形界面一般也提供注册表与代理的设置入口。

三、容器内的代理

  • 在运行容器时传入代理环境变量。
  • 在 compose 文件里统一声明。
  • 需要访问内网服务的，把内网地址加入排除列表。

四、镜像加速

配合镜像加速地址，常用镜像拉取速度更快，两者可以结合。

五、注意事项

不要把含有代理地址的配置提交到公开仓库；使用后确认代理确实生效，并定期更新容器镜像。
